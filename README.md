# Kishor Timsina Personal Website

Static GitHub Pages website for `kishortimsina.com.np`.

## Files

- `index.html` - main one-page website.
- `styles.css` - responsive visual design.
- `script.js` - mobile navigation and active section state.
- `assets/hero-structural-engineering.png` - generated website hero image.
- `assets/kishor-headshot.jpg` - professional portrait used in the hero.
- `assets/kishor-field-portrait.jpg` - portrait used in the contact section.
- `assets/kishor-mountain-portrait.jpg` - field image used in the about section.
- `assets/cv-kishor-timsina.pdf` - downloadable CV.
- `assets/aem-model.png` - Applied Element Method research visual.
- `assets/stone-masonry-rural.png` - rural stone masonry building visual.
- `assets/earthquake-damage.jpg` - earthquake damage research visual.
- `assets/soft-story-damage.jpg` - soft-storey damage research visual.
- `assets/sri-lab-utm.jpeg` - SRI Lab universal testing machine.
- `assets/bamboo-measurement.jpeg` - bamboo measurement photo.
- `assets/bamboo-samples.jpeg` - bamboo sample preparation photo.
- `assets/bamboo-tensile-test.jpeg` - bamboo tensile test photo.
- `assets/masonry-wallet-samples.jpg` - stone masonry wallet samples.
- `assets/masonry-reaction-frame.jpg` - masonry reaction frame setup.
- `CNAME` - custom domain for GitHub Pages.

## Deploy

1. Put these files at the root of the GitHub repository.
2. In GitHub, open Settings > Pages.
3. Select the branch you want to publish, usually `main`, and the root folder.
4. Keep `CNAME` in the repository so GitHub Pages uses `kishortimsina.com.np`.
5. Configure the domain DNS with your domain provider if it is not already pointed to GitHub Pages.
